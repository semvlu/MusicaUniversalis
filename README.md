# Musica Universalis : Employing MIDI Dataset for Composer Recognition
## Description
> Phase 1: Adopt the similarity methods, including cosine, dynamic time warping (DTW), and Euclidean similarities.

> Phase 2: Extract MIDI piano roll and chroma roll, train with SVM, CNN, LSTM, and Transformer-based models for classification.
## Dataset
[MAESTRO v3.0.0](https://magenta.tensorflow.org/datasets/maestro)
